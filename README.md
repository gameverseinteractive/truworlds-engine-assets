# TruWorlds Game Engine Assets
Provided are assets used in the TruWorlds engine. You can use these assets to create content for TruWorlds.

The avatar rig is provided as a reference to use to create your own animations in TruWorlds Creator. The provided Blender file supports Blender versions 5.2.2 LTS and newer.
